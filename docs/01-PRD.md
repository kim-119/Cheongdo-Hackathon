# 01. PRD — 가림AI

## 한 줄
"개인정보는 내 서버에서 가리고, 일은 AI가 한다." 민원·업무 문서를 안전하게 AI로 처리하는 공무원 개인 업무 비서 웹앱.

## 사용자
- **주 사용자**: 청도군 민원·행정 담당 공무원
- **상황**: 하루 수십 건 민원 회신, 공문 작성, 회의록 정리, 지침 PDF·민원 대장 엑셀 확인

## 핵심 기능 (MVP)
| ID | 기능 | 설명 | 우선 |
|---|---|---|---|
| F1 | 개인정보 가림 | 텍스트·문서의 이름·전화·주민번호·주소·계좌·이메일·차량번호를 `[이름_1]` 형태로 치환, 하이라이트 | P0 |
| F2 | AI 업무 실행 | 가린 텍스트로 ①민원 답변 초안 ②요약 ③공문 초안 ④할 일 추출 | P0 |
| F3 | 복원 | 결과의 토큰을 원문 값으로 되돌림 (VM 안에서만) | P0 |
| F4 | 전송 확인 | 외부로 보낼 텍스트 미리보기 + 사용자 승인 | P0 |
| F8 | 문서 업로드·인덱싱 | PDF·Excel 업로드 → 가림 → 청크 → 임베딩 → 벡터DB 저장. 원본 파일은 저장 안 함 | P0 |
| F9 | 문서 질의응답(RAG) | 업로드 문서에 질문 → 근거 청크 인용(쪽/시트·행)과 함께 JSON 규칙대로 답변 | P0 |
| F5 | 할 일 보드 | F2-④·F9 결과의 할 일을 오늘/이번 주/완료 보드에 저장 | P1 |
| F6 | 전송 기록 | 외부 전송 시각·종류·모델·가린 항목 수·차단 여부 | P1 |
| F10 | 에이전트 활동 표시 | 에이전트가 호출한 툴(할 일 추가·기한 설정)을 결과 화면에 표시 | P1 |
| F7 | 모바일 | Capacitor Android 앱 (반응형 웹으로 대체 가능) | P2 |

## 사용자 스토리
1. 민원 원문을 붙여넣으면 3초 안에 개인정보가 색으로 표시된다.
2. "답변 초안"을 누르면 외부 전송본을 확인 후 승인한다.
3. 초안은 원래 이름·연락처가 복원된 상태로 받는다.
4. 민원 처리 지침 PDF를 올리고 "경로당 보조금 신청 기한이 언제야?"라고 물으면, 근거 쪽수와 함께 답을 받는다.
5. 민원 대장 엑셀을 올리고 "이번 주 처리 기한인 건 알려줘"라고 물으면, 해당 행을 인용해 답하고 할 일 보드에 쌓인다.

## 비기능
- 원문 PII 외부 유출 **0건** (붙여넣기·문서 경로 모두)
- 붙여넣기 1건 처리 ≤ 10초 · 문서 질의 ≤ 15초 · 10쪽 PDF 인덱싱 ≤ 60초
- 모바일 화면 대응

## 성공 지표
PII 재현율 ≥ 95% · 유출 0 · RAG hit@5 ≥ 0.8 · JSON 스키마 준수 100% · 작성 시간 50%↓

## 제외
로그인, HWP/HWPX·스캔 PDF(OCR)·xls 파싱, 결재 시스템 연동, 다중 테넌트
