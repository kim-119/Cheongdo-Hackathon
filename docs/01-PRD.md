# 01. PRD — 가림AI

## 한 줄
"개인정보는 내 서버에서 가리고, 일은 AI가 한다." 공무원 개인 업무 비서 웹앱.

## 사용자
- **주 사용자**: 청도군 민원·행정 담당 공무원
- **상황**: 하루 수십 건 민원 회신, 공문 작성, 회의록 정리

## 핵심 기능 (MVP)
| ID | 기능 | 설명 | 우선 |
|---|---|---|---|
| F1 | 개인정보 가림 | 붙여넣은 텍스트의 이름·전화·주민번호·주소·계좌·이메일·차량번호를 `[이름_1]` 형태로 치환, 하이라이트 표시 | P0 |
| F2 | AI 업무 실행 | 가린 텍스트로 ①민원 답변 초안 ②요약 ③공문 초안 ④할 일 추출 | P0 |
| F3 | 복원 | 결과의 토큰을 원문 값으로 되돌려 보여줌 (서버 메모리에서만) | P0 |
| F4 | 전송 확인 | 외부로 보낼 텍스트 미리보기 + 사용자 승인 | P0 |
| F5 | 할 일 보드 | F2-④ 결과를 오늘/이번 주 보드에 저장 | P1 |
| F6 | 전송 기록 | 외부 전송 시각·모델·가린 항목 수·차단 여부 | P1 |
| F7 | 모바일 | Capacitor Android 앱 | P2 |

## 사용자 스토리
1. 민원 원문을 붙여넣으면 3초 안에 개인정보가 색으로 표시된다.
2. "답변 초안"을 누르면 외부 전송본을 확인 후 승인한다.
3. 초안은 원래 이름·연락처가 복원된 상태로 받는다.
4. 처리할 일이 자동으로 할 일 보드에 쌓인다.

## 비기능
- 원문 PII 외부 유출 **0건**
- 1건 처리 ≤ 10초
- 모바일 화면 대응

## 성공 지표
재현율 ≥ 95% · 유출 0 · 작성 시간 50%↓

## 제외
로그인, HWP 파싱, 결재 시스템 연동, 다중 테넌트
