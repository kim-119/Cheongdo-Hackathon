## 3. 통합
| 시나리오 | 방법 | 기대 |
|---|---|---|
| LocalAgent JSON 파싱 | LM Studio mock | 깨진 JSON → 재시도 1회 → 실패 시 정규식 결과만 |
| LM Studio 다운 | mock 503 | 붙여넣기: 정규식만 + 경고 / 인덱싱: 임베딩 불가 → 503 + 안내 |
| **클라우드 전송 내용** | 클라우드 provider를 가짜 서버로 교체, 수신 본문 캡처 (`/run`, `/ask` 모두) | 원문 PII 0건 |
| DB 저장 내용 | 인덱싱 후 `chunks.text_masked`·`todos` 전수 검사 | 원문 PII 0건 |
| 매핑표 TTL | 10분 경과 | `/run` 410 |
| 근거 없음 | 무관한 질문 | 클라우드 호출 0회, `notFound: true` |
| `add_todo` 툴 | 할 일 추출 / 문서 질의 | DB에 n건 저장 |

## 4. 평가
- **PII** (`eval.pii`): `eval/cases/pii/*.json` 가상 민원 30건 + 가상 PDF 3개·엑셀 2개 + 정답 엔티티 → 재현율·정밀도·p50/p95·유출 건수
- **RAG** (`eval.rag`): 가상 문서 위 질문 20개 + 정답 chunk → hit@5, 인용 정확도, JSON 준수율, notFound 정확도
- CI 게이트: PII 재현율 ≥ 95%, 유출 = 0, hit@5 ≥ 0.8, JSON 준수 100%
- CI에는 LM Studio가 없음 → `--record`로 LLM·임베딩 응답을 `eval/fixtures`에 녹화, CI는 재생
- 결과 표를 README `<!-- EVAL:START/END -->`에 자동 반영
